Special Features is a Paratext tool that points out the places where published Bibles often use special formatting: genealogies, lists, letters, prayers, inscriptions, acrostics, Old Testament quotations and more. The places come from the paper "Special Layout Features found in Old and New Testaments", which compared seven Bibles. For each place it shows the markers usually used, the markers your project already uses there, and whether the place is still plain paragraphs. You can add your own places, and share them with others. The tool only reads the project; it changes nothing.
